# Auto Clicker

High-performance auto-clicker with animated PySide6 GUI.

## Features

- **3 click modes**: Smooth, Insta, Mixed (random CPS between min/max)
- **CPS presets**: 100, 200, 300, 400, 500 — or any custom value
- **Live CPS counter** — real-time display
- **Bind system** — bind any key or mouse button
- **Hold / Toggle** modes
- **Hide/Show bind** — hotkey to toggle window visibility (opens on top)
- **Only Roblox** mode — clicks only when Roblox is focused
- **Dark & Light themes** — readable, animated, glow effects on hover
- **Frameless window** — draggable, always on top
- **Optimized** — low CPU, high CPS (up to 500+)

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
python run.py
```

## Requirements

- Python 3.10+
- PySide6
- pynput

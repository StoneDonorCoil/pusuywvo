# 🤖 Мой AI Бот

Полностью свой AI-бот с веб-интерфейсом. Работает на локальной модели через [Ollama](https://ollama.ai) — никаких внешних API, никаких ограничений на запросы.

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![FastAPI](https://img.shields.io/badge/FastAPI-latest-green)
![Ollama](https://img.shields.io/badge/Ollama-local_AI-purple)

## ✨ Возможности

- 💬 Красивый адаптивный чат-интерфейс (работает на телефоне, планшете, ПК)
- 🧠 Полностью локальная AI модель — без внешних API и ограничений
- 📚 Своя база знаний — бот знает то, что ты ему дашь
- 🎭 Настраиваемая личность через системный промпт
- ⚡ Потоковая генерация ответов (streaming) — ответ появляется по мере генерации
- 🔄 Поддержка множества моделей (можно переключать)
- 🐳 Docker-контейнеры для простого развёртывания

## 🚀 Быстрый старт

### Вариант 1: Docker (рекомендуется)

Самый простой способ — запуск через Docker Compose:

```bash
# 1. Клонируй репозиторий
git clone https://github.com/StoneDonorCoil/pusuywvo.git
cd pusuywvo

# 2. Запусти всё одной командой
docker compose up -d

# 3. Загрузи модель (первый раз займёт несколько минут)
docker exec ollama ollama pull llama3

# 4. Открой в браузере
# http://localhost:8000
```

### Вариант 2: Ручная установка

```bash
# 1. Установи Ollama
# Linux:
curl -fsSL https://ollama.ai/install.sh | sh

# macOS:
# Скачай с https://ollama.ai/download

# Windows:
# Скачай с https://ollama.ai/download

# 2. Загрузи модель
ollama pull llama3

# 3. Клонируй проект и установи зависимости
git clone https://github.com/StoneDonorCoil/pusuywvo.git
cd pusuywvo
pip install .

# 4. Запусти бота
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

# 5. Открой http://localhost:8000
```

## 📚 Как обучить бота (подробная инструкция)

### Способ 1: Системный промпт (личность бота)

Файл `knowledge/system_prompt.txt` определяет **кто** твой бот и **как** он себя ведёт.

**Примеры:**

```text
Ты — помощник интернет-магазина "МегаШоп".
Твоя задача — помогать покупателям с выбором товаров, отвечать на вопросы о доставке и оплате.
Будь вежливым и профессиональным.
Не обсуждай темы, не связанные с магазином.
```

```text
Ты — персональный репетитор по математике.
Объясняй сложные темы простым языком.
Используй примеры из реальной жизни.
Если ученик ошибается, мягко поправляй и объясняй почему.
```

```text
Ты — весёлый бот-собеседник по имени Алекс.
Шути, используй эмодзи, общайся как друг.
Помогай с любыми вопросами, но в лёгкой манере.
```

### Способ 2: База знаний (что бот знает)

Добавляй `.txt` файлы в папку `knowledge/` — бот автоматически будет использовать эту информацию:

```
knowledge/
├── system_prompt.txt      ← личность бота
├── faq.txt               ← часто задаваемые вопросы
├── products.txt          ← информация о товарах
├── company_info.txt      ← информация о компании
└── rules.txt             ← правила и политики
```

**Пример `knowledge/faq.txt`:**
```text
Вопрос: Как оформить возврат?
Ответ: Для возврата товара свяжитесь с нами в течение 14 дней с момента покупки.
Отправьте товар в оригинальной упаковке на наш адрес.

Вопрос: Какие способы оплаты доступны?
Ответ: Мы принимаем банковские карты, Apple Pay, Google Pay и наличные при получении.
```

### Способ 3: Выбор модели

Разные модели подходят для разных задач:

| Модель | Размер | Лучше для | RAM |
|--------|--------|-----------|-----|
| `llama3` | 4.7 ГБ | Универсальный ассистент | 8 ГБ |
| `llama3:70b` | 40 ГБ | Максимальное качество | 64 ГБ |
| `mistral` | 4.1 ГБ | Быстрые ответы | 8 ГБ |
| `gemma2` | 5.4 ГБ | Креативные задачи | 8 ГБ |
| `phi3` | 2.3 ГБ | Минимальные ресурсы | 4 ГБ |
| `codellama` | 3.8 ГБ | Программирование | 8 ГБ |
| `llama3:8b-instruct-q4_0` | 4.7 ГБ | Баланс скорость/качество | 8 ГБ |

```bash
# Загрузи нужную модель
ollama pull mistral

# Или через Docker
docker exec ollama ollama pull mistral
```

Переключать модель можно прямо в интерфейсе чата (выпадающий список справа вверху).

### Способ 4: Создание своей модели (Modelfile)

Для продвинутой настройки можно создать свой `Modelfile`:

```bash
# Создай файл Modelfile
cat > Modelfile << 'EOF'
FROM llama3

# Настройка параметров генерации
PARAMETER temperature 0.7
PARAMETER top_p 0.9
PARAMETER num_ctx 4096

# Системный промпт встроенный в модель
SYSTEM """
Ты — помощник компании "ТехноМир".
Ты знаешь всё о наших продуктах и услугах.
Отвечай кратко и по делу. Используй русский язык.
"""
EOF

# Создай свою модель
ollama create my-custom-bot -f Modelfile

# Используй её
# Измени MODEL_NAME=my-custom-bot в .env
```

## ⚙️ Настройка

### Переменные окружения

Скопируй `.env.example` в `.env` и настрой:

```bash
cp .env.example .env
```

| Переменная | Описание | По умолчанию |
|-----------|---------|--------------|
| `OLLAMA_BASE_URL` | Адрес Ollama сервера | `http://localhost:11434` |
| `MODEL_NAME` | Название модели | `llama3` |
| `APP_TITLE` | Название бота в интерфейсе | `Мой AI Бот` |
| `APP_HOST` | Хост сервера | `0.0.0.0` |
| `APP_PORT` | Порт сервера | `8000` |

### GPU ускорение (NVIDIA)

Для быстрой генерации раскомментируй секцию GPU в `docker-compose.yml`:

```yaml
deploy:
  resources:
    reservations:
      devices:
        - driver: nvidia
          count: all
          capabilities: [gpu]
```

Убедись что установлен [NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/install-guide.html).

## 🌐 Доступ с любого устройства

### Локальная сеть

Бот уже доступен по локальному IP (если запущен с `0.0.0.0`):

```bash
# Узнай свой IP
ip addr show | grep "inet " | grep -v 127.0.0.1

# Открой на любом устройстве в той же сети:
# http://192.168.1.XXX:8000
```

### Доступ через интернет

**Вариант A: Cloudflare Tunnel (бесплатно, рекомендуется)**

```bash
# Установи cloudflared
# https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/

# Создай туннель
cloudflared tunnel --url http://localhost:8000
```

**Вариант B: Свой сервер (VPS)**

Арендуй VPS (например, на Timeweb, Selectel, Hetzner) и разверни через Docker.

**Вариант C: Ngrok**

```bash
ngrok http 8000
```

## ❓ FAQ

**Q: Бот отвечает медленно. Что делать?**
- Используй модель поменьше (`phi3`, `mistral`)
- Добавь GPU (раскомментируй секцию в docker-compose.yml)
- Увеличь RAM сервера

**Q: Как обновить базу знаний без перезапуска?**
- База знаний перечитывается при каждом запросе, поэтому просто измени файлы в `knowledge/`

**Q: Можно ли использовать несколько моделей одновременно?**
- Да! Загрузи несколько моделей в Ollama и переключайся через интерфейс

**Q: Бот забывает контекст разговора?**
- Контекст хранится в рамках одной сессии. При обновлении страницы чат сбрасывается

**Q: Как ограничить доступ к боту?**
- Добавь nginx с basic auth перед ботом, или используй Cloudflare Access

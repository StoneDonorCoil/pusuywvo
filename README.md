# 🎓 Edu Store — Telegram Bot

Телеграм-бот для продажи обучающих видеоматериалов с системой заказов и админ-панелью.

## Возможности

- **Каталог курсов** — 3 направления обучения с прайс-листом
- **Оплата** — реквизиты для перевода через ЮMoney / карту
- **Заказы** — создание и отслеживание статуса заказов
- **Админ-панель** — подтверждение/отклонение оплат, статистика
- **Автоуведомления** — покупатель получает ссылку на канал после подтверждения

## Быстрый старт

### 1. Установка
```bash
pip install -r requirements.txt
```

### 2. Настройка
Отредактируйте `config.py`:
- `BOT_TOKEN` — токен бота от @BotFather
- `ADMIN_ID` — ваш Telegram ID (узнать: отправьте `/myid` боту)
- `SUBCATEGORIES` → `channel_link` — ссылки на ваши закрытые каналы
- `SUPPORT_CONTACTS` — контакты поддержки

### 3. Запуск
```bash
python bot.py
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню |
| `/menu` | Показать меню |
| `/myid` | Узнать свой Telegram ID |
| `/admin` | Панель администратора (только для админа) |

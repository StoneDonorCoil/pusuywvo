# MC Events — Плагины ивентов для Minecraft Bedrock (Nukkit)

Коллекция из **10 готовых ивент-плагинов** для серверов на платформе Nukkit / PowerNukkit.

## Плагины

| # | Плагин | Команда | Описание |
|---|--------|---------|----------|
| 1 | **SurvivalGames** | `/sg` | Голодные Игры — PvP на выживание с сужающейся границей, фазой deathmatch и настраиваемым лутом |
| 2 | **TreasureHunt** | `/th` | Охота за Сокровищами — ищите спрятанные сокровища по подсказкам "горячо/холодно" с системой рейтинга |
| 3 | **BossRaid** | `/boss` | Рейд на Босса — совместный бой с боссом, фазы сражения, награды по вкладу в урон |
| 4 | **BuildBattle** | `/bb` | Битва Строителей — строительство на заданную тему с голосованием игроков |
| 5 | **KingOfTheHill** | `/koth` | Царь Горы — захват и удержание точки, очки за время в зоне |
| 6 | **MobArena** | `/ma` | Арена Мобов — волновой ивент с нарастающей сложностью и волнами боссов |
| 7 | **Spleef** | `/spleef` | Сплиф — ломайте блоки под ногами противников, последний на арене побеждает |
| 8 | **ParkourRace** | `/parkour` | Паркур-Гонка — соревнование на время с чекпоинтами и таблицей рекордов |
| 9 | **LuckyBlocks** | `/lb` | Лаки-Блоки — ломайте особые блоки для случайных наград/ловушек |
| 10 | **DropParty** | `/dp` | Дроп-Пати — предметы падают с неба, собирай больше всех! |

## Сборка

Требования:
- Java 17+
- Maven 3.6+

```bash
# Собрать все плагины
mvn clean package

# Собрать один плагин
cd plugins/survival-games
mvn clean package
```

Скомпилированные `.jar` файлы будут в `plugins/<название>/target/`.

## Установка

1. Скопируйте `.jar` файл в папку `plugins/` вашего Nukkit сервера
2. Перезапустите сервер
3. Отредактируйте `config.yml` в папке `plugins/<ИмяПлагина>/`
4. Перезагрузите конфиг: `/<команда> reload`

## Структура проекта

```
├── pom.xml                    # Родительский Maven проект
├── docs/
│   └── SERVER_IDEAS_50.md     # 50 идей для сервера
└── plugins/
    ├── survival-games/        # Голодные Игры
    ├── treasure-hunt/         # Охота за Сокровищами
    ├── boss-raid/             # Рейд на Босса
    ├── build-battle/          # Битва Строителей
    ├── king-of-the-hill/      # Царь Горы
    ├── mob-arena/             # Арена Мобов
    ├── spleef/                # Сплиф
    ├── parkour-race/          # Паркур-Гонка
    ├── lucky-blocks/          # Лаки-Блоки
    └── drop-party/            # Дроп-Пати
```

Каждый плагин содержит:
- `src/main/java/` — исходный код
- `src/main/resources/plugin.yml` — метаданные плагина
- `src/main/resources/config.yml` — настройки (с подробными комментариями на русском)
- `src/main/resources/messages.yml` — все сообщения (кастомизируемые)

## Настройка

Все настройки находятся в файлах `config.yml` каждого плагина с подробными комментариями на русском языке. Основные параметры:

- Длительность ивентов
- Количество игроков (мин/макс)
- Награды (деньги, предметы)
- Таблицы лута
- Координаты арен (устанавливаются через команды)
- Все текстовые сообщения (через `messages.yml`)

БАЗА ЗНАНИЙ: ЯЗЫКИ ПРОГРАММИРОВАНИЯ

=== Python ===
Высокоуровневый язык с простым синтаксисом. Используется для: веб-разработки (Django, Flask, FastAPI), машинного обучения (TensorFlow, PyTorch), автоматизации, анализа данных.
Особенности: динамическая типизация, отступы вместо скобок, богатая стандартная библиотека.
Пример: print("Hello, World!")

=== JavaScript ===
Язык веб-разработки. Работает в браузере и на сервере (Node.js). Фреймворки: React, Vue, Angular, Next.js, Express.
Особенности: асинхронность, прототипное наследование, Event Loop.
Пример: console.log("Hello, World!");

=== TypeScript ===
Надмножество JavaScript с статической типизацией от Microsoft. Компилируется в JS.
Используется: крупные проекты, React/Angular приложения.
Пример: const greet = (name: string): string => `Hello, ${name}!`;

=== Java ===
Объектно-ориентированный язык. "Напиши один раз — запускай везде" (JVM). Используется: Android-приложения, корпоративные системы (Spring Boot), финтех.
Особенности: строгая типизация, сборка мусора, многопоточность.
Пример: System.out.println("Hello, World!");

=== C# ===
Язык от Microsoft для .NET платформы. Используется: игры (Unity), Windows-приложения, веб (ASP.NET), мобильные (Xamarin/MAUI).
Особенности: LINQ, async/await, свойства, события.
Пример: Console.WriteLine("Hello, World!");

=== C++ ===
Мощный язык для системного программирования. Используется: игры (Unreal Engine), ОС, драйверы, высокопроизводительные системы.
Особенности: ручное управление памятью, шаблоны, множественное наследование.
Пример: std::cout << "Hello, World!" << std::endl;

=== C ===
Базовый системный язык. Используется: ОС (Linux ядро), встроенные системы, IoT, драйверы.
Особенности: указатели, прямой доступ к памяти, минимальная абстракция.
Пример: printf("Hello, World!\n");

=== Go (Golang) ===
Язык от Google. Используется: микросервисы, облачные системы (Docker, Kubernetes написаны на Go), CLI-инструменты.
Особенности: горутины (concurrency), быстрая компиляция, статическая линковка.
Пример: fmt.Println("Hello, World!")

=== Rust ===
Системный язык с гарантиями безопасности памяти. Используется: системное ПО, WebAssembly, блокчейн, CLI.
Особенности: ownership, borrowing, zero-cost abstractions, нет сборщика мусора.
Пример: println!("Hello, World!");

=== Swift ===
Язык Apple для iOS/macOS разработки. Используется: iPhone/iPad приложения, macOS, watchOS.
Особенности: опционалы, протоколы, расширения, ARC.
Пример: print("Hello, World!")

=== Kotlin ===
Современный язык для JVM от JetBrains. Официальный для Android. Используется: Android, серверные приложения (Ktor), мультиплатформа.
Особенности: null-safety, корутины, расширения, data classes.
Пример: println("Hello, World!")

=== PHP ===
Серверный язык для веб. Используется: WordPress, Laravel, Symfony, веб-сайты.
Особенности: встроен в HTML, огромная экосистема, простой деплой.
Пример: echo "Hello, World!";

=== Ruby ===
Элегантный язык для веб-разработки. Ruby on Rails — популярный фреймворк. Используется: стартапы, прототипы, веб-приложения.
Особенности: всё — объект, блоки, метапрограммирование.
Пример: puts "Hello, World!"

=== Dart ===
Язык от Google для Flutter. Используется: кроссплатформенные мобильные приложения (iOS + Android из одного кода).
Особенности: горячая перезагрузка, виджеты, async/await.
Пример: print('Hello, World!');

=== SQL ===
Язык запросов к базам данных. Используется: MySQL, PostgreSQL, SQLite, MS SQL, Oracle.
Операции: SELECT, INSERT, UPDATE, DELETE, JOIN, GROUP BY.
Пример: SELECT * FROM users WHERE age > 18;

=== HTML/CSS ===
HTML — разметка веб-страниц. CSS — стилизация.
HTML5: семантические теги, canvas, video, audio.
CSS3: flexbox, grid, анимации, переменные, медиа-запросы.

=== Bash/Shell ===
Скриптовый язык для Unix/Linux. Используется: автоматизация, DevOps, CI/CD.
Пример: echo "Hello, World!"

=== Lua ===
Лёгкий скриптовый язык. Используется: игры (Roblox, WoW модификации), встроенные системы, nginx.
Пример: print("Hello, World!")

=== R ===
Язык для статистики и анализа данных. Используется: наука, биоинформатика, финансы, визуализация.
Пример: print("Hello, World!")

=== Scala ===
Функциональный + ОО язык на JVM. Используется: Big Data (Apache Spark), серверные системы.
Пример: println("Hello, World!")

=== Haskell ===
Чисто функциональный язык. Используется: академия, финтех, компиляторы.
Особенности: ленивые вычисления, монады, паттерн-матчинг.
Пример: main = putStrLn "Hello, World!"

=== Assembly (Ассемблер) ===
Низкоуровневый язык, близкий к машинному коду. Используется: оптимизация, реверс-инжиниринг, embedded.
Архитектуры: x86, ARM, MIPS, RISC-V.
